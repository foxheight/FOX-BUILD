## Core Values

### 1. SOVEREIGNTY IS NON-NEGOTIABLE

Every byte of client data has a documented jurisdiction. Every piece of infrastructure is owned and operated by Fox Height. Every system is auditable, transparent, and under client control.

### 2. ZERO MISTAKES IS THE ENTRY CONDITION

Code that has not been tested does not ship. Documentation that is not complete is not documentation. Zero mistakes is not an aspiration. It is how we build.

### 3. TRANSPARENCY IS TRUST

We document everything. Why this file exists. Why this decision was made. What the trade-offs were. Trust is earned through radical transparency.

### 4. AFRICA FIRST

We build for East Africa. We price in Kenyan Shillings. We operate in East Africa Time. We comply with Kenya DPA 2019 by design, not by default.

### 5. PERMANENCE OVER HYPE

We do not chase trends. We build systems that will be valuable in 2035. Long-term thinking is our competitive advantage.

### 6. HUMANS REMAIN IN CONTROL

Every AI system we build has a human override. Every decision can be reversed. Every action can be audited. Technology serves humans.
